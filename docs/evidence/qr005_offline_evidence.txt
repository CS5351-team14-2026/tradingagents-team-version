QR005-03 — isolated env: external blocked, loopback OK, full suite
-----------------------------------------------------------------
  Tool     : tools/ci/isolation_preflight.py  (runs OUTSIDE pytest)
  Endpoint : tools/ci/controlled_endpoint.py  (temporary TCP listener)
  Procedure:
    1. Start the endpoint on the host: bound 0.0.0.0, port 0 -> chosen port P.
       Numeric non-loopback host address H (this host: 172.18.110.113).
    2. CONTROL, outside the namespace, same H:P:
         $ python tools/ci/isolation_preflight.py control --host H --port P
         PREFLIGHT external H:P reachable=True (connected)
         PREFLIGHT loopback ok=True (127.0.0.1:<ephemeral> reachable)
         PREFLIGHT control PASSED                                    (exit 0)
    3. ISOLATED, inside `unshare -Urn` with `ip link set lo up`, same H:P:
         $ unshare -Urn sh -c 'ip link set lo up &&
             python tools/ci/isolation_preflight.py isolated --host H --port P'
         PREFLIGHT external H:P reachable=False (OSError: [Errno 101] Network is unreachable)
         PREFLIGHT loopback ok=True (127.0.0.1:<ephemeral> reachable)
         PREFLIGHT isolated PASSED                                   (exit 0)
  Result: ordinary environment reaches the endpoint; the isolated namespace
  cannot; 127.0.0.1 bind/connect works in both. Negative paths also checked
  (control vs blocked -> exit 1; isolated vs reachable -> exit 1).
  Covered by: test/offline/test_isolation_preflight.py (7 tests, mocked probes);
              test/offline/test_controlled_endpoint.py (2 tests, local bind/accept).
